# 연구 노트 02 — 펀딩비 캐리: 과열 심리를 수익으로 바꾸기

작성: 2026-11-08 (연구 노트 01 "과열 심리는 무엇을 예측하는가"에서 이어짐, 실험 4까지 반영)

## 한 줄 결론
> 펀딩비가 높은 코인(들뜬 군중)을 그냥 숏 치면 가끔 오는 폭등에 다 날린다. 같은 코인의 현물을 사서 가격 위험을 지우면, 남는 펀딩비 수취는 처음 보는 코인에서도 재현되는 진짜 엣지다. 하지만 교체 비용과 청산 비용까지 넣은 자본 대비 수익은 연 약 3% (선물 1배, 샤프 약 3) — 스테이블코인 예치 같은 무위험 이자를 확실히 이길 만큼 크지는 않다.

## 출발점 (연구 노트 01에서)
- 과열(펀딩비 + OI + RSI)은 방향이 아니라 폭발을 예고한다
- BTC·ETH 옵션 시장은 이를 이미 가격에 반영, 알트코인은 반영 안 됨
- 방향 베팅·그리드·추세 추종 모두 실패 → 방향과 무관하게 버는 구조가 필요

## 공통 설정

- 기존 15종목(단서 찾는 곳) + 검증 15종목(처음 보는 곳) 동시 테스트, 규칙은 결과 보기 전에 확정
- 리밸런싱: 매주 월요일 00:00 UTC, 신호 = 지난 7일 펀딩비 합계

## 실험 1 — 펀딩비로 코인 고르기 (시장 중립 롱숏, 가격 위험 그대로)

| | 기존 15종목 | 검증 15종목 |
|---|---|---|
| 가격 차이 (주) | −1.34% (t −1.07) | −0.05% (t −0.08) |
| **펀딩비 수취 (주)** | **+0.28% (t 6.7, 승률 95%)** | **+0.44% (t 9.8, 승률 95%)** |
| 순수익 (주) | −1.20% | +0.24% (t 0.36) |
| 최악의 주 | **−149.9%** (숏 코인 폭등) | −47.7% |
→ 실패. 가격 쪽에서 숏 스퀴즈 한 방에 전부 잃음
- 펀딩비 3분위: 높음 구간의 다음 주 **중앙값은 가장 낮고(−1.99%) 평균은 가장 높음(+3.88%)** → 연구 01과 같은 패턴 (대부분 식지만 가끔 폭발)

→ **엣지는 펀딩비 수취, 문제는 가격 위험** → 가격 위험만 지우면 된다

## 실험 4 — 과열 적응형 레버리지 (완충 + 시장가 그대로, 청산 비용 반영)
비교: 전부 2배 / 전부 1배 / 적응형 (직전 24시간 과열 코인 1배, 나머지 2배)
청산 처리: 보유 중 최고 상승률 ≥ 1/L − 0.5% → 강제청산, 순손실 = 청산 수수료 1% + 재진입 0.19% (명목 대비)
판정 (미리 정함): 적응형 샤프 > 전부 2배 샤프, 두 데이터 모두
| 자본 대비 연수익 / 샤프 / 청산 | 기존 15종목 | 검증 15종목 |
|---|---|---|
| 전부 2배 | +3.4% / 2.50 / 12건 | +2.8% / 1.84 / 17건 |
| 전부 1배 | +3.1% / **3.07** / 3건 | +3.1% / **3.15** / 2건 |
| 적응형 | +3.3% / 2.46 / 11건 | +2.7% / 1.84 / 16건 |
→ **적응형 실패.** 과열 진입 포지션이 14~18개뿐이고, 청산의 대부분(12건 중 11건, 17건 중 16건)이 과열 신호 **없던** 포지션에서 발생 → 캐리를 위협하는 급등은 대부분 과열 신호 밖에서 온다
→ (사후 관찰, 판정 기준 아님) **전부 1배가 두 데이터 모두 샤프 최고**. 2배의 자본 효율 이득을 청산 비용이 거의 다 먹음. 검증 종목에서는 수익률도 1배가 더 높음
→ 청산 비용 반영 후 실제 자본 대비 수익 **연 약 3%**

## 냉정한 평가
1. **수익 크기**: 청산 비용까지 넣은 자본 대비 연 약 3% (1배). 스테이블코인 예치 같은 거의 무위험 이자(대략 연 4~5% 수준)보다 낮을 수 있음 → **지금 형태 그대로는 무위험 이자를 확실히 이기지 못함**
2. **키울 여지**: 지정가 주문(비용 절반 → 연 1~2%p 추가), 펀딩비가 높은 상승장, 증거금에 이자가 붙는 계좌 방식 여부
3. **백테스트에 없는 위험**
   - 거래소 위험: 현물·선물이 한 거래소에 집중
   - 체결 위험: 알트 호가가 얇아 실제 슬리피지가 가정보다 클 수 있음
   - 펀딩비 정산 주기·상한 변경, 상장폐지
4. **종목 선정 편향**: "현재" 상위 종목을 과거에 적용한 한계는 연구 01과 동일

## 배운 점
- 실패한 전략도 손익을 쪼개 보면 진짜 엣지가 숨어 있다 (실험 1: 가격은 실패, 펀딩비는 t 7~10)
- 엣지가 있어도 비용이 다 먹을 수 있다 → 교체 빈도는 전략 설계의 핵심
- 개선은 결과를 보고 고르지 말고, 이미 확인된 성질(펀딩비 지속성)에 근거해서 하나만
- 레버리지의 자본 효율 이득은 청산 비용과 함께 따져야 한다 (2배 < 1배)
- 위험 신호(과열)가 그 전략의 실제 위험 원인과 같은지 확인해야 한다 (캐리 청산은 대부분 과열 밖에서 발생)
- 검증된 엣지 ≠ 할 만한 전략 → 무위험 대안과 비교해야 한다
