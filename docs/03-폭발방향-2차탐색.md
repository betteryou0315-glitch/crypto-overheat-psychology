# 연구 노트 03 — 과열 후 폭발 방향, 2차 탐색

작성: 2026-11-08 밤 ~ 11-10 (연구 노트 01·02에서 이어짐) — **방향 탐색 종료. 판정 6개 통과 0. "롱 과열 → 폭발"은 하락장(2022~2023)에서도 재현**

## 배경
- 연구 01: 롱 과열(펀딩비 ≥ 0.02% + RSI ≥ 70 + OI 1시간 증가)은 폭발을 강하게 예고하지만 방향은 반반. 쏠림·베이시스·레짐·오더북·청산 대리 지표 모두 방향 예측 실패
- 연구 02: 펀딩비 캐리는 진짜 엣지지만 자본 대비 연 약 3%로 무위험 이자 수준 → 중단
- 목표: 그래도 폭발 **방향**을 맞히고 싶다 → 처음 보는 코인 세트·기간을 따로 받아두고, 가설은 그 데이터를 보기 전에 등록

## 실험 결과

### 1. 가짜 돌파 역매매 (`fakeout.py`) — 기각 (기존 30종목에서)
신호 시점 24시간 고점/저점을 처음 뚫고 1시간 안에 종가 복귀하면 반대 진입
- 전체 거래당 −0.25% / −0.06%. 과열 후 기준선 돌파의 약 75%가 1시간 안에 종가 복귀 — 단, 복귀 후 다시 치솟는 경우도 많음

### 2. 지켜보고 따라가기 (`wait_follow.py`) — 기각 (기존 30종목에서)
신호 후 4시간 동안 ±2% 이상 움직인 방향으로 진입, 24시간 청산
- 합산 −1.23% (군집t −2.52), 방향 일치율 46~47%

### 3. 과열 후 하락 반등 (`dip_rebound_final.py`) — **최종 기각** (`data_final`)
| | 기존 | 검증 | **최종 (판정)** |
|---|---|---|---|
| 거래당 평균 | +2.77% | +1.80% | **+0.46% (t 0.36)** |
| 중앙값 | +0.25% | −0.17% | **−1.43%** |
→ "대부분 잃고 가끔 폭등하는" 복권 구조

### 4. 추정 청산 맵 (`liqmap.py`) — **최종 기각** (`data_final`)
순위상관: 기존 −0.045 / 검증 +0.003 / **최종 +0.006 (t 0.17)**

### 5. CVD — 폭발 첫 순간의 시장가 주문 우위 (`cvd.py`) — **최종 기각** (두 번 판정)
첫 ±2% 폭발 직전 15분의 시장가 매수/매도 우위가 움직인 방향과 같을수록 지속?
| | 기존 | 검증 | 최종 (판정 1, t ≥ 2.5) | **과거 2022~23 (판정 2, t ≥ 2.3)** |
|---|---|---|---|---|
| 폭발 사건 | 700 | 768 | 544 | 63 |
| 순위상관 (군집t) | +0.031 (1.08) | −0.008 (−0.22) | +0.072 (2.31) | **−0.214 (−1.71)** |
| 약함 → 중간 → 강함 (지속−반전) | +2% → −1% → +10% | −0% → +1% → −1% | −13% → +3% → +8% | **+48% → +10% → −14%** |
→ 최종 세트에서 가설 모양(기준 미달), 과거 하락장에서는 **정반대** → 시장 국면에 따라 뒤집히는 신호 → 기각

### 6. 두 번째 돌파 = 진짜 폭발? (`second_break.py`) — **최종 기각** (`data_new`)
| | 기존 | 검증 | 최종 | **새 46~60위 (판정)** |
|---|---|---|---|---|
| 거래당 평균 (군집t) | +1.05% (0.96) | −0.12% (−0.14) | +0.06% (0.15) | **+0.64% (1.14)** |
| 중앙값 | −0.86% | −1.27% | −0.81% | **−1.27%** |
**시점 (네 세트 모두 일관)**: "첫 가짜 → 두 번째 돌파" 60~63%, 첫 돌파가 진짜 19~21%, 두 번째 돌파까지 중앙 2.2~3.0시간

### 7. 숏 과열 (`short_overheat.py`) — 탐색에서 종료
숏 과열 = 펀딩비 ≤ −0.02% + RSI ≤ 30 + OI 1시간 증가
- 기준 대비 폭발률 1.44 / 1.05 / 1.11배 (롱 과열은 1.49~1.56배) → 폭발 예고는 **롱 과열만의 성질**
- 방향은 세트마다 뒤집힘 (−10% / −8% / +13%) → 등록 안 함

### 8. 청산 흡수 (`absorption.py` → `absorption_final.py`, `past_verdict.py`) — **기준 미달 / 판정 불가**
롱 과열 후 첫 청산 투매(5분 −1.5% + 매도 3배 + OI −1%) 직후 15분 저점 유지 + 매도 ≥ 매수 = 흡수
- 청산 투매는 흔함 (롱 과열의 약 45~60%), 흡수는 드묾 (투매의 약 6~14%)
| | 46~60 + 61~75위 (판정 1) | 과거 2022~23 (판정 2) |
|---|---|---|
| 흡수 건수 | 32 | **6** |
| 4시간 순수익 평균 / 중앙값 | +2.06% / −0.08% | −0.47% / +0.02% |
| 판정 | 기준 미달 (t 1.52) | 판정 불가 (너무 적음) |
→ 흡수가 너무 드물어 공개 데이터로는 확인 어려운 구조

### 9. 과거 하락장(2022-01 ~ 2023-10)에서 "롱 과열 → 폭발" 재확인 (`past_verdict.py` 참고 항목)
| | 2023-11 이후 (주로 상승장, 4개 세트) | **2022-01 ~ 2023-10 (하락장, 28종목)** |
|---|---|---|
| 과열 사건 | 550~781 / 세트 | **69** (28종목 중 17종목만 사건 있음) |
| 24시간 ±5% 폭발률 | 77~81% | **64%** |
| 신호 없는 봉 폭발률 | 49~54% | 41% |
| 기준 대비 | 1.49~1.56배 | **1.56배** |
| 먼저 위 / 아래 / 안 터짐 | 38~41% / 36~40% / 19~23% | **19% / 45% / 36%** |
→ **"롱 과열 → 평소의 약 1.5배 잘 터진다"는 시장 국면과 상관없이 재현** (다른 코인 + 다른 시기 + 하락장)
→ 하락장에서는 펀딩비 0.02% 초과 자체가 드물어 사건이 적음
→ 새 관찰: 하락장에서는 폭발이 **아래로 크게 기움** (19% vs 45%). 상승장에서는 거의 반반 → "폭발 방향은 시장 전체 흐름을 따라간다"는 가능성. 단, 69건짜리 한 시기의 사후 관찰 → 관찰 목록

## 결론
- 처음 보는 데이터로 판정한 방향 가설 6개(하락 반등, 청산 맵, CVD ×2, 두 번째 돌파, 청산 흡수) **통과 0개**
- CVD는 상승장 세트에서 가장 근접했지만 하락장에서 정반대 → 국면 의존 신호는 사용 불가
- 반복되는 패턴은 방향이 아니라 **꼬리**: 평균은 플러스, 중앙값은 0 이하
- **시점은 일정**: 과열 후 약 1시간 안에 첫 돌파(대부분 가짜), 약 3시간 무렵 두 번째 돌파
- **가장 단단한 결론 강화**: 롱 과열 → 평소의 약 1.5배 잘 터진다 — 75종목 5개 세트 + 2022~23 하락장 28종목에서 모두 재현. 숏 과열은 약함
- **방향 탐색 종료 (2026-11-10 결정)** — "롱 과열 → 곧 폭발"은 킵, 다른 연구로 이동

## 관찰 목록 (미래·다른 국면 데이터로만 확인 가능)
- 하락장에서는 롱 과열 폭발이 아래로 기움 (2022~23: 위 19% / 아래 45%)
- 시장 전체 과열(BTC 30일 급등) 상태의 개별 코인 과열 → 아래로 (연구 01, 홀드아웃 통과)

- 투매 직후 성급한 시장가 매수 몰림("반등" 그룹) → 이후 4시간 약세 (사후 관찰)
