# 연구 노트 01 — 과열 심리는 무엇을 예측하는가

작성: 2026-11-08 (방향 탐색 종료 + 변동성 예측력 분해 + 옵션·그리드·추세 활용 검증까지 반영)

## 한 줄 결론
> 가격이 과열된 상태(RSI)에서 레버리지까지 몰리면(펀딩비 + OI) 곧 폭발한다. 이건 단순히 최근에 많이 움직였기 때문도, 가격이 많이 올랐기 때문도 아니다. 폭발의 방향은 알 수 없고, BTC·ETH 옵션 시장은 이 폭발을 이미 가격에 반영한다. 옵션 시장이 없는 알트코인에서는 "잔잔할 때 버는 전략"을 폭발에서 지키는 필터로 작동한다.

## 질문
"펀딩비 과열 + RSI 과매수 + OI 증가" 상태(= 군중이 레버리지 롱에 몰린 상태)가 되면 가격은 어떻게 움직이는가?

## 데이터와 공통 설정
- 출처: data.binance.vision (바이낸스 USDT 무기한 선물), Deribit DVOL (BTC·ETH 30일 내재변동성 지수)
- 기간: 2023-11 ~ 2026-10 (3년), 15분봉
- 종목: 현재 24시간 거래대금 상위 15개 **코인** (금·주식·ETF 같은 전통자산 선물은 제외)
- 과열 신호: 직전 펀딩비 ≥ 0.02%, RSI(14) ≥ 70, OI가 1시간 전보다 증가
- 같은 신호가 연속으로 켜지면 첫 봉만 사용 (직전 4시간에 신호가 없을 때 = 독립 사건) → 718건
- 비용: 수수료 편도 0.04% (돌파 전략은 슬리피지 0.02% 추가)
- 알려진 한계: "현재" 상위 종목을 과거에 적용함 (종목 선정 편향), 신규 상장 코인은 이력이 짧음

### 14. 옵션 매수 — 과열 순간 옵션이 실제 이후 변동성보다 쌌는가 (BTC·ETH, DVOL)

### 16. 알트코인 중립 그리드 + 과열 필터 (설정 미리 확정, 결과 보고 조정 안 함)
그리드: 매일 00:00 UTC 리셋, 간격 0.5%, 범위 ±5% (위아래 10칸, 범위 끝에서 1배), 범위 이탈 시 전부 청산, 하루 끝 청산, 지정가 0.02% / 시장가 0.05%, 15분봉 종가 경로(봉 안 왕복은 놓침)
비교: A 매일 / B 시작 전 필터(직전 24h 과열이면 쉼) / C 실시간 정지(과열 신호 뜨면 즉시 청산)
| 포트폴리오 하루평균 (샤프) | 기존 15종목 | 검증 15종목 |
|---|---|---|
| A. 매일 그리드 | −0.575% (−13.7) | −0.628% (−15.8) |
| B. 시작 전 필터 | −0.521% (−12.9) | −0.562% (−14.6) |
| C. 실시간 정지 | −0.556% (−13.4) | −0.603% (−15.3) |
- **그리드 자체가 큰 손실 전략** (승률 21~27%). 랜덤 데이터에서는 ≈0(+0.01%) → 계산 오류 아님. 범위 이탈 손절·하루 마감 구조가 손실을 만든 것으로 추정 (17번에서 "알트코인은 추세적" 해석은 기각)
- 필터는 두 데이터 모두에서 제 역할:
| | 기존 15종목 | 검증 15종목 |
|---|---|---|
| B 쉰 날 vs 돌린 날 (종목·일 평균) | −1.02% vs −0.55% | −1.12% vs −0.61% |
| 최악 1% 종목·일 중 B가 피한 비율 (전체 쉰 날 비율) | 13% (5%) | 11% (6%) |
| C 정지한 날: 그대로 → 멈춤 | −0.99% → −0.49% | −1.07% → −0.50% |
→ 쉰 날이 실제로 손실 2배 가까이 큰 날, 최악의 날 회피율은 우연 대비 약 2배, 실시간 정지는 그날 손실을 절반으로
→ 옵션 시장이 없는 알트코인에서는 과열 정보가 가격에 반영되지 않아 **필터로 작동** (옵션 매도와 대조)
→ 단, 지켜줄 기초 전략이 돈을 벌어야 의미 있음

### 17. 알트코인 추세 추종 (터틀식 채널 돌파) + 과열 필터 (규칙 미리 확정)
진입: 종가가 직전 24시간 최고가 돌파 → 롱 / 최저가 이탈 → 숏. 청산: 반대쪽 12시간 채널 이탈. 편도 비용 0.07%
| A 기본, 거래당 (군집t) | 기존 15종목 (10,081건) | 검증 15종목 (9,270건) |
|---|---|---|
| 전체 | −0.01% (−0.15) | −0.29% (−3.34) |
| 롱 | **+0.33%** (1.69) | −0.24% (−1.74) |
| 숏 | −0.36% (−3.14) | −0.34% (−2.67) |
| 포트폴리오 연 / 샤프 | −3.2% / −0.07 | −59.4% / −1.85 |
→ **기초 전략으로 실패.** 기존 종목의 롱 우위는 검증 종목에서 뒤집힘 (재현 실패)
→ 비용 전으로도 검증 종목 약 −0.15% → 비용 문제가 아니라 추세 자체가 없음
→ 숏(하락 돌파 추종)은 두 데이터 모두 일관되게 비용 이상 손실 → 하락 돌파 후 되돌림이 잦음
→ 16번의 "알트코인은 하루 안에서 추세적" 해석은 기각 (그리드 손실은 구조 탓으로 보임)
- B 과열 필터: 건너뛴 거래가 기존 +0.39% / 검증 −0.81%로 반대 → 추세 전략에서는 필터 효과 일관되지 않음
- 건너뛴 거래의 평균 이익 +8~10%, 평균 손실 −4.3~4.7% (평소의 약 2배) → 과열 = 폭발 구간 재확인

## 결론
1. **가격 과열 + 레버리지 유입이 동시에 오면 곧 폭발한다.** 24시간 내 ±5% 폭발 78% → 처음 보는 15개 코인에서도 81%로 재현.
2. 이 예측력은 **변동성 군집만으로도, RSI만으로도 설명되지 않는다.** 같은 변동성·같은 RSI 과열에서 펀딩비+OI가 더해지면 폭발 확률 +17%p (두 데이터 모두 t 5~9).
3. **방향은 예측하지 못한다** (위 41% / 아래 36~40%). 돌파를 따라가도 휩쏘에 털린다.
4. 방향 단서로 안 통한 것: 돌파 추종, 코인 자체 추세, 테이커 매수비율, 큰손 롱숏 단독, 프리미엄 변화 속도, 레버리지 쏠림 점수(홀드아웃 기각), 오더북 불균형(24시간·1시간 모두), 청산 후 반전(전체) → **방향 탐색 종료**
5. **BTC·ETH 옵션 시장은 이 정보를 이미 가격에 반영한다** (과열 때 IV 급등). 옵션 매수로도, 옵션 매도 필터로도 추가 이익 없음.
6. **옵션 시장이 없는 알트코인에서는 위험 필터로 작동한다** — 그리드에서 쉰 날은 손실이 2배 가까이 큰 날, 실시간 정지 시 그날 손실 절반 (두 데이터 모두 재현). 추세 전략에서는 필터 효과가 일관되지 않음.
7. 테스트한 기초 전략(중립 그리드, 채널 돌파 추세)은 모두 손실 → 필터의 실전 가치는 수익성 있는 기초 전략을 찾은 뒤에 확인 가능.

> 과열 상태 파악 → 대부분 곧 폭발 → 방향은 반반. 주요 코인 옵션 시장은 이미 알고, 알트코인에서는 위험 필터로 쓸 수 있다.

## 연구 과정에서 배운 함정
- 미래 데이터 참조 (스윙 고점은 k봉 뒤에야 확정)
- 종목 섞임 (전통자산 선물이 거래대금 상위에 들어옴)
- 꼬리가 만든 평균 착시 (평균 vs 중앙값, 꼬리 자르기)
- 결과 보고 종목/조건 고르기 (과최적화) → 홀드아웃, 미리 정한 가설로 대응
- 천천히 변하는 값의 t 부풀림 → 월 단위 군집 t
- 조건을 계속 바꿔 시도하면 언젠가 우연히 통과 → 시도 횟수 미리 제한
- "예측력 있음"이 이미 알려진 효과(변동성 군집, 가격 지표)의 재포장일 수 있음 → 같은 변동성·같은 RSI끼리 매칭해서 분리
- 예측력이 있어도 시장이 이미 가격에 반영했을 수 있음 → 그 정보를 거래하는 시장의 가격(IV)과 비교
- 근사 계산의 낙관 편향 (30일 IV로 1일 옵션 계산 등) → 놀라운 수익은 먼저 의심
- 필터의 효과와 기초 전략의 수익성은 별개 → "쉰 날이 더 나빴나"와 "전체가 돈을 버나"를 따로 확인
- 한 전략의 실패에서 반대 전략의 성공을 추론하면 안 됨 (그리드 손실 ≠ 추세 수익) → 반대 전략도 따로 검증
