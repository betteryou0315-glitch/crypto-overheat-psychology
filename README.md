# 과열 심리는 무엇을 예측하는가 — 암호화폐 선물 시장 연구

> **롱 과열(펀딩비 + RSI + OI)은 평소의 약 1.5배 잘 터진다. 방향은 모른다.**

## 작업 방식
| 역할 | 담당 |
|---|---|
| 연구 질문, 전략 가설 설정 | 직접 |
| 결과 해석, 다음 실험 방향 결정 | 직접 |
| 코드 구현 | AI(Claude) 활용 |

## 질문과 동기
금융 시장도 결국 사람의 심리로 움직인다. 그렇다면 시장이 과열됐을 때를 노려보면 되지 않을까?

군중이 레버리지 롱에 몰린 상태를 세 가지 조건으로 정의하고, 그 뒤에 가격이 어떻게 움직이는지 검증했다.

| 조건 | 기준 | 의미 |
|---|---|---|
| 펀딩비 | 직전 펀딩비 ≥ 0.02% | 롱이 숏에게 돈을 내면서까지 버팀 |
| RSI(14) | ≥ 70 | 가격이 과열됨 |
| OI | 1시간 전보다 증가 | 새 레버리지가 계속 들어옴 |

- 데이터: 바이낸스 USDT 무기한 선물 15분봉, 펀딩비, OI ([data.binance.vision](https://data.binance.vision)), Deribit DVOL
- 기간: 2023-11 ~ 2026-10 (본 검증), 2022-01 ~ 2023-10 (하락장 재검증)
- 같은 신호가 연속으로 켜지면 첫 봉만 사용 (독립 사건)

## 핵심 결과

### 1. 과열 후 24시간 안에 ±5% 폭발할 확률
| 데이터 | 과열 사건 폭발률 | 평소 봉 폭발률 | 배수 |
|---|---|---|---|
| 거래대금 1~15위 (단서 찾기) | 77.8% | 50.2% | 1.5배 |
| 16~30위 (처음 보는 코인) | 81.2% | 54.4% | 1.5배 |
| 31~75위 (처음 보는 코인 3세트) | 77~81% | 49~54% | 1.5배 |
| **2022-01 ~ 2023-10 하락장 (28종목)** | **64%** | **41%** | **1.56배** |

→ 다른 코인, 다른 시기, 하락장에서도 같은 배수로 재현된다.

### 2. 단순히 "많이 움직이던 코인"이라서가 아니다
같은 변동성, 같은 RSI 과열 상태의 봉과 비교해도 펀딩비 + OI가 더해지면 폭발 확률이 높아진다.

| 같은 변동성의 "RSI만 과열" → "셋 다 과열" | 1~15위 | 16~30위 |
|---|---|---|
| 폭발률 | 60.1% → 77.8% (**+17.7%p**, t 6.15) | 64.3% → 81.2% (**+17.0%p**, t 9.05) |

→ 가격 과열(불씨)과 레버리지 유입(연료)이 만나야 폭발한다. 각각만으로는 약하다.

### 3. 방향은 반반
24시간 안에 ±5% 중 먼저 닿는 쪽: 위 38~41% / 아래 36~40% (상승장). 하락장에서는 아래로 기울었다 (위 19% / 아래 45%).

## 검증 방법
결과를 보고 규칙을 고치는 과최적화를 피하려고 다음 원칙을 지켰다.
- **홀드아웃**: 거래대금 순위로 코인을 15개씩 나눠, 단서 찾기에 쓰지 않은 세트에서만 판정
- **미리 등록한 가설**: 판정 데이터를 열기 전에 가설, 방향, 통과 기준(t 값)을 먼저 적어둠. 같은 데이터를 다시 쓸수록 기준을 높임 (t 2 → 2.3 → 2.5)
- **변동성 매칭**: 최근 변동성 10분위가 같은 봉끼리 비교해 "변동성 군집"과 "과열 정보"를 분리
- **월 단위 군집 t**: 같은 시기 사건끼리 겹쳐 t가 부풀려지는 것을 보정
- **꼬리 확인**: 평균과 중앙값을 함께 보고, 소수의 큰 사건이 만든 착시인지 확인
- **랜덤 데이터 검사**: 계산 오류가 없는지 무작위 데이터로 확인

## 실패한 것들
폭발의 **방향**을 맞히려는 시도는 모두 실패했다. 처음 보는 데이터로 판정한 방향 가설은 **6개 중 통과 0개**다.

| 시도 | 결과 |
|---|---|
| 저항구간 숏 (원래 아이디어) | 본전 근처, 통계적으로 0과 구분 안 됨 |
| 돌파 방향 추종 | 휩쏘에 털림 (9개 조합 모두 유의하지 않음) |
| 롱숏 비율, 베이시스, 오더북 불균형, 청산 대리 지표 | 처음 보는 데이터에서 재현 안 됨 |
| 가짜 돌파 역매매, 두 번째 돌파, 하락 반등, 청산 맵 | 최종 판정 기각 |
| CVD (시장가 주문 우위) | 상승장 세트에서 근접, 하락장에서 정반대 → 기각 |
| 옵션 매수 | BTC·ETH 옵션 시장은 과열 때 IV가 이미 올라 있음 → 시장이 이미 알고 있음 |
| 펀딩비 캐리 (현물 롱 + 선물 숏) | 진짜 엣지지만 비용 반영 후 자본 대비 연 약 3% → 무위험 이자 수준 |

과열 신호는 방향 예측이 아니라 **위험 필터**로 쓸 수 있다. 옵션 시장이 없는 알트코인 그리드에서, 과열 직후 쉰 날은 실제로 손실이 2배 가까이 큰 날이었다.
